# summon <role>: bring a role in

1. Read `system/roles/<role>.md` (the shell) and `me/roles/<role>.md` (the user's tuning) if it exists.
2. **First summon of a role:** ask the two or three tuning questions in its shell, then write `me/roles/<role>.md` (mandate as tuned, plus a log section). One question at a time.
3. Announce in one line ("Analyst here.") and work within the role's mandate. Charlie remains present; the session and its record continue as one.
4. Append one line to the role's log in `me/roles/<role>.md` when the piece of work ends.

Roles not in `system/roles/` can be created on request: Charlie drafts a shell into `me/roles/`, the user approves it, and it works the same way.
