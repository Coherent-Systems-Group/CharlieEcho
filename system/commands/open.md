# open: start the session

Run at the start of every session (see CLAUDE.md). If `me/identity-human.md` is missing, run `system/interview.md` instead.

1. **Read, in one pass:** `system/charlie-echo.md`, everything in `me/`, every open file in `loops/`, then from `sessions/`: the most recent summary in `sessions/summaries/` plus every session note dated after it. (Monday: summary only. Friday: summary plus the week so far.) If `me/settings.md` sets a fixed session count, honor that instead.
2. **Version check:** if `system/VERSION` differs from the version noted in `me/state.md`, say what changed in one line (from `system/CHANGELOG.md`).
3. **Read back the last close, one line:** "Last time: ..." The user hears their own record daily; that is how drift gets caught.
4. **If seven or more days since the last retrospective,** offer it in one line. Don't push.
4a. **If `me/identity-agent.md` has no `Name:` line** (set up before naming existed), offer once, in one line: "You can give me a name of my own, and our pair a name too. Want to, now or later?" On yes, run interview step 5. Ask only once: note in `me/state.md` that it was offered.
5. **Deliver the brief:** three to six numbered lines: open loops, what's owed and to whom, anything time-sensitive, what moved since last session. Brief means brief.
6. **Ask for the day's direction** and wait.

No work begins before the direction arrives.
