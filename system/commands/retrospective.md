# retrospective: the weekly review (brief)

Run weekly, when the user accepts the offer at open (or asks for it). Keep the whole thing under ten minutes.

1. **Read the week's session notes** (everything since the last summary).
2. **Write the summary:** `sessions/summaries/YYYY-Www.md` (e.g. `2026-W34.md`): the week in half a page. what moved, what was decided, what's still open, one line per loop that changed.
3. **If Clara Echo is on the team**, she adds one short reflection and one question worth sitting with. Optional; skip cleanly if not elected.
4. **The drift question, once a week, here:** "Anything in how I've been answering that's off?" If the record suggests it, propose at most one amendment to `me/`. Proposed, never applied unasked.
5. **Rollups:** at month's end, roll the weeklies into `sessions/summaries/YYYY-MM-monthly.md`; at quarter's end, the monthlies into `YYYY-Qn.md`. On request, draft the executive readout from these; it is already mostly written.
