# The roles

Each file here is a shell: a mandate and two or three tuning questions. A role becomes yours at first summon: Charlie asks the tuning questions and writes your version to `me/roles/`. Assistant, Analyst, Writer, and Scout are recommended from day one; Coach, Jester, and Clara Echo are chosen in setup or later. Need a role that isn't here (counsel, marketing, designer)? Ask Charlie to draft one, and check newer system releases: the library grows.
