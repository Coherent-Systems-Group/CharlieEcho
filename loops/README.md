# loops/ (open threads of work)

Bigger than a task, smaller than a project. One file each, numbered in order of opening: `L001-short-name.md`, `L002-...`. The brief reads these; the close updates them. Yours; updates never touch this folder.

Every loop starts with this header:

```
---
status: open
opened: YYYY-MM-DD (Snnn)
---
# Title
One line on what this is and why it matters.
Next: the single next action.
```

Close a loop by setting `status: closed`. Don't delete it; closed loops are the record of what got done.
